# Python Strings

## 1. Introduction
A string in Python is a sequence of characters enclosed within single quotes (' '), double quotes (" "), or triple quotes (''' ''' or """ """).

Strings are used to store and manipulate text data such as names, addresses, messages, and sentences.

## 2. Key Concepts
- Creating Strings
- Accessing Characters using Indexing
- String Slicing
- String Length using `len()`
- String Concatenation
- String Repetition
- String Formatting
- String Immutability
- Checking Substrings using `in` and `not in`

## 3. Common String Methods

| Method | Description |
|---|---|
| `upper()` | Converts to uppercase |
| `lower()` | Converts to lowercase |
| `capitalize()` | Capitalizes the first character |
| `title()` | Capitalizes the first letter of each word |
| `strip()` | Removes leading and trailing spaces |
| `replace()` | Replaces a specified substring |
| `split()` | Splits a string into a list |
| `join()` | Joins elements into a string |
| `find()` | Finds the position of a substring |
| `count()` | Counts occurrences of a character or substring |

## 4. Example

```python
name = "python programming"

print(name.upper())
print(name.lower())
print(name.capitalize())
print(len(name))
print(name.replace("python", "Java"))
```

## 5. Sample Output

```text
PYTHON PROGRAMMING
python programming
Python programming
18
Java programming
```

## 6. Important Points
- Strings are immutable in Python.
- String indexing starts from 0.
- Negative indexing starts from -1.
- Strings support slicing.
- Python provides several built-in methods to manipulate strings.
