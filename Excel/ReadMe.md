## 3. Common Excel Functions

| Function | Description |
|---|---|
| `SUM()` | Calculates the total |
| `AVERAGE()` | Calculates the average |
| `COUNT()` | Counts numeric values |
| `COUNTA()` | Counts non-empty cells |
| `MAX()` | Returns the maximum value |
| `MIN()` | Returns the minimum value |
| `IF()` | Performs logical tests |
| `VLOOKUP()` | Searches for data vertically |
| `XLOOKUP()` | Searches for matching values |
| `SUMIF()` | Calculates totals based on a condition |
| `COUNTIF()` | Counts cells based on a condition |
| `TRIM()` | Removes extra spaces |
| `CONCAT()` | Combines text values |
